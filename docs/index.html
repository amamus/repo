❌ Not Covered by ecosyste.ms

The following data sources exist but are not exposed through ecosyste.ms APIs:

  • Docker Hub total pulls: Available via Docker Hub API but not aggregated in ecosyste.ms
  • download.owncloud.com tarball downloads: ownCloud's own download server statistics
  • PyPI download statistics: PyPI removed native download stats in 2018
  • Marketplace/extension downloads: ownCloud app marketplace statistics
  • Enterprise/on-premise deployments: Not trackable via public registries

Note: This page intentionally separates "real" download counters from partial signals to avoid implying that the data presents a complete adoption picture. The ecosyste.ms project aggregates data from many sources, but some important metrics remain outside its scope.
